A tiny brain that learns to write children's stories — explained in plain English.

1 What is MiniGPT-JAX?
📖

It reads stories

It learns from 1,000 short children's stories called TinyStories.

🎛️

It has dials

Millions of numbers ("weights") that get adjusted during training.

✍️

It writes new text

Given a prompt, it predicts the next word — over and over.

⚡

Powered by JAX

JAX is like NumPy on turbo — runs fast on CPU, GPU, or TPU.

🔤
Token + Position Embedding
Words → numbers the model can do maths on
🔁
6 × Transformer Block (Multi-Head Attention)
Each block lets every word look at every word before it
📊
Linear Output Layer → 50,257 scores
One score per word in the GPT-2 vocabulary
📐 Embed dim: 192 🗣️ Heads: 6 🏗️ Blocks: 6 📏 Max context: 128 tokens 📚 Vocab: 50,257 tokens

  • Reads all stories as one long stream of tokens.
  • Chops it into fixed-length windows of 128 tokens each (batches of 24).
  • For each window: predict the next token, measure how wrong it was (cross-entropy loss), nudge the weights to be less wrong.
  • Learning rate warms up for 10% of steps, then cosine-decays from 3e-4 → 1e-5.
  • After 20 full passes through the data the weights are saved to minigpt_checkpoint.orbax.
3 How does it write a story?
  • Step 1 — Encode: "Once upon a time" → [7454, 2402, 257, 640]
  • Step 2 — Forward pass: tokens go through all 6 transformer blocks.
  • Step 3 — Scores: model outputs a score for all 50,257 words.
  • Step 4 — Top-K filter: keep only the top 40 words, set the rest to −∞.
  • Step 5 — Sample: pick one word randomly, weighted by the scores.
  • Step 6 — Repeat: append the new token and go back to Step 2.
  • Stop when we hit the <|endoftext|> token or the max token limit.

4 CLI Commands

Three commands, one module: python -m minigpt <command>

🏋️ train Step 1
# Train on 1,000 TinyStories for 20 epochs
python -m minigpt train \
  --data data/TinyStories-1000.txt \
  --epochs 20 \
  --checkpoint minigpt_checkpoint.orbax
  • Reads and tokenises the text file.
  • Runs AdamW with cosine LR schedule.
  • Saves weights to disk when done.
✍️ generate Step 2
# Continue a story from a prompt
python -m minigpt generate \
  --checkpoint minigpt_checkpoint.orbax \
  --prompt "Once upon a time" \
  --temperature 0.8 \
  --top-k 40 \
  --max-new-tokens 80
🌐 demo Web UI
# Launch Gradio web interface
python -m minigpt demo \
  --checkpoint minigpt_checkpoint.orbax \
  --share # optional: public link

AdamW + cosine LR. 20 epochs. Saved with Orbax.

Generate

Token by token. Top-K + temperature sampling.
